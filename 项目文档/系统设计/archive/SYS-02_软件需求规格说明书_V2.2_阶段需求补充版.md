# 1 文档目的

本文档定义 AircraftPoseSystem V2.1 软件需求规格。

**V2.2 补充**：新增 §5 阶段需求，规定各阶段的需求范围与虚拟 / 真实件构成，
补上 SYS-01 §24.5 对「SYS-02 的阶段需求」的引用。**需求条目本身未变。**

系统目标：

建立一套基于：

* 多相机视觉测量；
* 固定光机结构；

* 视觉闭环对准；
* PnP姿态求解；

的飞机相对舰体姿态测量系统。

## 5.1 当前阶段

系统当前处于：

```text id="s2ph02"

Phase 2  Hardware Integration

```

该阶段的过渡形态是 **CAM25 真实 + 其余虚拟**，依据 ENG-08 §3 当前资源映射：

```text id="s2ph03"

已有硬件        CAM25

虚拟设备        VirtualCamera50

                VirtualCamera100

                VirtualTurntable

                VirtualTrigger

```

---

## 5.2 替换顺序（冻结）

**先单件，后组合。** 不得一次性换掉全部虚拟件。

理由：三路同时接入时，任何一路失败都无法区分是"该路硬件问题"还是"多路协同问题"。

∴ 当前只推进 CAM25 一路：

```text id="s2ph04"

设备枚举

↓

打开相机

↓

单帧采集

↓

连续采集

↓

ImageFrame 填充

↓

预览

↓

RAW 保存

```

逐项**可观测**后才允许动第二路。

---

## 5.3 当前阶段的需求裁剪

| 需求 | 出处 | 当前阶段 | 理由 |
| --- | --- | --- | --- |
| 三相机同步采集 | §6.1 | 仅 CAM25 一路真实 | CAM50 / CAM100 为虚拟件 |
| 焦段选择 | §6.4 | 不验收 | 只有一路真实图像，判据的输入不成立 |
| 三路时间戳同步 | §6.1 | 不验收 | "一路真实 + 两路虚拟"下同步判据不成立 |
| Yaw ≤ 1角分 | §2.2 | 不验收 | 精度指标属 Phase 3 |
| 100ms 实时性 | §2.2 | 不验收 | 与精度同属 Phase 3 |

当前阶段验收的是"**真实相机链路可观测地跑通**"。

不得以"程序没报错"代替，也不得以"SDK 链路打通"代替设备枚举真的通过 ——
后者的典型失效是"**链路通了但没有数据**"。

---

## 5.4 ⚠ 实测：真实件是"诚实桩"，且未装配

ENG-08 §3 指定的虚拟 / 真实唯一切换点是 `SystemInitializer::buildDevices()`。
本次核查实测结果：

| 位置 | 装配点当前装配 | 真实后端类 | 真实后端的状态 |
| --- | --- | --- | --- |
| CAM25 / CAM50 / CAM100 | `VirtualCameraBackend` ×3 | `ImvCameraBackend` | **诚实桩**：所有方法返回 false |
| 触发 | `VirtualTriggerController` | `HardwareTriggerController` | **诚实桩**：所有方法返回 false |
| 转台 | `VirtualTurntable` | `PekoTurntableController` | **诚实桩**：所有方法返回 false |

⚠ **不得表述为"真实实现已就绪、只差装配"。** 实测是两件事都没做：

* **真实后端仍是诚实桩** —— 未接 SDK / 未接硬件，每个方法明确失败并说明原因；
* **装配点也还没有切换** —— 三个 `make_shared<VirtualCameraBackend>` 仍在原位。

∴ 011-A1 要**同时**完成这两件事。只做其中一件都得不到"真实相机链路跑通"。

⚠ **转台另有前置缺口**：`PekoTurntableController` 不含 Peko_D 协议报文构造，
因为协议帧结构未在冻结文档中给出（SYS-10 只列了支持的协议种类，未给帧结构）。
∴ 真实转台接入**受文档缺口阻塞**，不只是受硬件阻塞。

---

## 5.5 ⚠ 转台 / 触发阶段归属：三种读法不一致

| 来源 | 对 Phase 2 范围的表述 |
| --- | --- |
| SYS-01 §24.5 | 转台 = Real、触发 = Real（CAM25 亦为 Real） |
| ENG-08 §3 当前资源映射 | `VirtualTurntable`、`VirtualTrigger` 仍在虚拟设备清单内 |
| ENG-08 §17 Phase 2 输入 | "三相机接入、硬触发、转台SDK" 三项**同列** Phase 2 |
| 代码装配点 | 触发与转台仍装配虚拟件（见 §5.4） |

三种读法给出的 Phase 2 范围不同：

```text id="s2ph05"

读法 A（SYS-01 §24.5）   Phase 2 = CAM25 真实 + 转台/触发 真实
                          CAM50 / CAM100 留到 Phase 3

读法 B（ENG-08 §3）      Phase 2 = 仅 CAM25 真实
                          转台 / 触发 / 其余相机保持虚拟

读法 C（ENG-08 §17）     Phase 2 = 三相机 + 硬触发 + 转台SDK 全部接入

```

**本版不擅自裁定**，只如实登记。

唯一三种读法一致的部分是**"CAM25 单路先真实"** ——
故当前可执行的范围不受此冲突影响。
