# SYS-02_软件需求规格说明书_V2.1（三相机闭环测量版）

---

# 1 文档目的

本文档定义 AircraftPoseSystem V2.1 软件需求规格。

系统目标：

建立一套基于：

* 多相机视觉测量；
* 固定光机结构；
* 三焦段镜头协同；
* 标定参数冻结；
* 视觉闭环对准；
* PnP姿态求解；

的飞机相对舰体姿态测量系统。

---

# 2 系统概述

## 2.1 系统目标

系统实现：

```text id="v5p2kc"
目标检测

↓

视觉对准

↓

图像采集

↓

姿态解算

↓

舰体坐标输出

```

输出：

* 航向角Yaw；
* 俯仰角Pitch；
* 横滚角Roll。

# 4 硬件需求

## 4.1 相机需求

系统采用：

A7A20MU201。

要求：

| 参数  | 要求          |
| --- | ----------- |
| 分辨率 | 4096×3000   |
| 像元  | 3.45μm      |
| 快门  | 全局快门        |
| 接口  | USB3.0      |
| 触发  | 硬件外触发       |
| 输出  | Mono8/10/12 |

---

# 4.2 镜头需求

采用三焦段：

| 通道     | 镜头    |
| ------ | ----- |
| CAM25  | 25mm  |
| CAM50  | 50mm  |
| CAM100 | 100mm |

---

# 4.3 光学冻结要求

必须：

* 光圈固定；
* 对焦固定；
* 标定后锁死。

禁止：

运行过程中调整：

* 光圈；
* 对焦。

---

# 5 功能需求

---

# 5.1 多相机采集

系统应支持：

三相机同步采集。

输入：

```text id="u8v5ak"
CAM25

CAM50

CAM100

```

输出：

```text id="y5x7mq"
MultiCameraFrame
```

---

# 5.2 实时预览

系统应支持：

实时图像显示。

要求：

支持：

* 默认CAM25；
* 手动切换；
* 自动选择预览源。

---

# 5.3 目标检测

系统应支持：

目标区域检测。

输出：

* 目标位置；
* 检测置信度。

---

# 5.4 焦段选择

系统应根据：

* 距离估计；
* 目标像素大小；
* 图像质量；
* 特征数量；

选择最佳测量镜头。

---

禁止：

仅使用固定距离阈值切换。

---

# 5.5 特征匹配

系统应支持：

建立：

```text id="u3y6dk"
2D Image

↓

3D Model
```

对应关系。

支持：

* 自然纹理；
* CAD结构点。

---

# 5.6 姿态解算

系统应支持：

PnP姿态计算。

输入：

* 2D特征点；
* 3D模型点；
* 相机标定参数。

输出：

```text id="j7m2xw"
Aircraft→Camera
```

---

# 5.7 坐标转换

系统应支持：

```text id="w2j9nc"
Camera

↓

Rig

↓

Ship

```

转换。

---

# 5.8 转台闭环控制

系统应支持：

目标居中控制。

输入：

目标像素偏差：

```text id="z4x7pw"
TargetOffset
```

输出：

```text id="k9h3sa"
TurntableCommand
```
