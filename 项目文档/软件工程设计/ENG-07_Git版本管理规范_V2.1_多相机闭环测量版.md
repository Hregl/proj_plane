# AircraftPoseSystem Git版本管理规范 V2.1（多相机闭环测量版）

## 1 文档目的

本文档定义AircraftPoseSystem V2.1软件工程版本管理规范。

V2.1相比V2.0新增：

-   光机刚体标定管理；
-   三相机配置管理；
-   转台配置管理；
-   触发配置管理；
-   目标模型与特征库管理；
-   精度测试数据管理。

目标：

建立完整软件基线：

    代码

    +

    配置

    +

    标定

    +

    模型

    +

    测试数据

    +

    文档

的版本追踪体系。

------------------------------------------------------------------------

# 2 Git管理原则

项目采用：

    本地Git仓库

    +

    离线备份

    +

    版本标签

    +

    发布归档

模式。

不依赖：

-   公网GitHub；
-   公网GitLab；
-   云同步。

------------------------------------------------------------------------

# 3 Git管理对象

## 3.1 源代码

目录：

    src/

    tests/

包括：

-   C++源码；
-   CMake；
-   测试代码。

------------------------------------------------------------------------

## 3.2 配置文件

目录：

    config/

包括：

    camera.yaml

    optical_rig.yaml

    turntable.yaml

    trigger.yaml

    measurement.yaml

    validation.yaml

------------------------------------------------------------------------

## 3.3 标定文件

目录：

    calibration/

包括：

    cam25.yaml

    cam50.yaml

    cam100.yaml

    cam25_to_rig.yaml

    cam50_to_rig.yaml

    cam100_to_rig.yaml

    rig_to_ship.yaml

------------------------------------------------------------------------

## 3.4 模型文件

目录：

    models/

包括：

    aircraft/

    ├── points3d.yaml

    ├── feature25.bin

    ├── feature50.bin

    └── feature100.bin

------------------------------------------------------------------------

## 3.5 测试数据

目录：

    tests/golden/

包括：

-   标准图像；
-   标定数据；
-   期望结果。

------------------------------------------------------------------------

# 4 分支管理策略

采用：

    main

    develop

    feature/*

    release/*

    hotfix/*

------------------------------------------------------------------------

# 5 main分支

用途：

正式发布版本。

保存：

-   验收版本；
-   交付版本。

禁止：

直接开发。

------------------------------------------------------------------------

# 6 develop分支

用途：

主开发分支。

当前：

    V2.1多相机闭环测量主线

------------------------------------------------------------------------

# 7 feature分支规范

格式：

    feature/module-name

------------------------------------------------------------------------

## OpticalRig

    feature/optical-rig

内容：

-   光机结构；
-   标定。

------------------------------------------------------------------------

## Turntable

    feature/turntable-control

内容：

-   转台接口；
-   SDK适配。

------------------------------------------------------------------------

## Trigger

    feature/hardware-trigger

内容：

-   硬触发。

------------------------------------------------------------------------

## MeasurementSelector

    feature/measurement-selector

内容：

-   焦段选择；
-   评分策略。

------------------------------------------------------------------------

## TargetModel

    feature/target-model

内容：

-   CAD模型；
-   特征库。

------------------------------------------------------------------------

## Algorithm

    feature/algorithm-pipeline

内容：

-   YOLO；
-   SIFT；
-   PnP。

------------------------------------------------------------------------

# 8 release分支

测试冻结。

    release/v2.1-framework

流程：

    develop

    ↓

    release

    ↓

    测试

    ↓

    main

    ↓

    tag

------------------------------------------------------------------------

# 9 Commit规范

格式：

    [type][module]: description

------------------------------------------------------------------------

# 10 Commit类型

## feat

新增功能：

示例：

    feat[optical]: add OpticalRig

------------------------------------------------------------------------

## fix

问题修复：

    fix[device]: fix camera timeout

------------------------------------------------------------------------

## refactor

重构：

    refactor[data]: update ShipPoseResult

------------------------------------------------------------------------

## test

测试：

    test[turntable]: add virtual test

------------------------------------------------------------------------

## docs

文档：

    docs[architecture]: update V2.1 design

------------------------------------------------------------------------

# 12 软件基线冻结

正式版本必须绑定：

    代码commit

    +

    config版本

    +

    calibration版本

    +

    model版本

    +

    test报告

例如：

    Release V2.1

    Code:
    commit xxxx

    Calibration:
    rig_cal_v1

    Model:
    aircraft_model_v1

    Test:
    report_v1

------------------------------------------------------------------------

# 13 标定版本管理

标定变化必须独立提交。

例如：

    calibration:update rig_to_ship

禁止：

代码修改与标定变化混合提交。

------------------------------------------------------------------------

# 14 模型版本管理

模型必须记录：

-   来源；
-   生成时间；
-   特征算法版本；
-   参数。

例如：

    aircraft_feature_v1.bin

------------------------------------------------------------------------

# 15 测试版本管理

测试数据必须绑定：

-   软件版本；
-   模型版本；
-   标定版本。

------------------------------------------------------------------------
