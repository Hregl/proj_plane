**本 Sprint 必做项：`RetryManager`（原清单遗漏）**

原任务清单只要求"完成业务状态机"，未包含 `RetryManager`。按 SYS-08 §7 的冻结结论，**没有 `RetryManager` 就无法实现有界的状态机**（全部恢复路径将退化为无限循环）。因此本 Sprint 必须同时交付：

1. `RetryManager` 类（接口见 SYS-08 §7.6）；
2. `MeasurementConfig` 的 16 个重试/超时字段（ENG-09 §6.5）与其 yaml 加载；
3. SYS-08 §10 的收敛性测试 7 个用例（可注入短 `T_task`，如 2 s）。

**本 Sprint 的两项前置任务（新增，来自 ENG-10 §10）**

这两项必须**排在本 Sprint 的算法链完整接入之前**，因为它们是 SYS-15 误差预算中最大未闭环环节的验证点，不能等到 Phase 2 实物试验才暴露。

**任务 A：`CadStructureLocator` 可行性验证（ENG-10 §2.3）**

| 项 | 内容 |
|---|---|
| 目的 | 验证"投影—匹配—拟合三步法"能否达到 **0.3 pixel** 的单点定位精度 |
| 输入 | Golden 数据集（ENG-06 §10）+ CAD 模型（须满足 ENG-10 §6 的棱线要求） |
| 判据 | 亚像素拟合残差 ≤ 0.3 pixel；与人工标注的结构点位置偏差 ≤ 0.5 pixel |
| 不通过的后果 | **SYS-15 §4.5 的 0.20 角分特征定位预算不成立**，总预算上升，可能突破 1 角分指标。此时须回到 SYS-15 重算预算，**不得假设该环节会自行达标** |

**任务 B：E 项 predictor 标定（ENG-10 §3.5）**

| 项 | 内容 |
|---|---|
| 目的 | 拟合 `σ_px_est = a + b·(1/S) + c·(1/C)` 的系数 `a,b,c` |
| 输入 | 36 格覆盖（3 焦段 × 4 距离段 × 3 光照）的 Golden 数据 |
| 判据 | 预测 E 与实际 PnP 残差的 **Spearman 相关系数 ≥ 0.5** |
| 产出 | 系数写入 `MeasurementConfig`；`predictedErrorCalibrated` 置 true |
| 顺序要求 | **必须先于 `w1~w4` 的整定**——E 不可信时调 `w4` 没有意义 |

**验收（本 Sprint）：**

输出：

    Yaw

    Pitch

    Roll

**且：** 任务 A、B 的判据均已给出结论并记录——**无论通过与否**，不通过时的结论同样必须记录，因为它直接改变 SYS-15 的误差预算。
