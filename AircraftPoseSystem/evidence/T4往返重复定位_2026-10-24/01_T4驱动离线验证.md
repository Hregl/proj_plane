## 1 目的与固定目标

T4 在固定两点 A/B 间往返，按目标分别统计：

* **反馈偏差**：每次到位反馈减命令目标（`feedback - target`）；
* **重复性**：同一目标多次到位的偏差总体标准差、极差、最大绝对偏差；
* **不混合**：A、B 分开统计；A/B 相同坐标直接拒绝，避免伪造重复性。

默认模式 `A,B,A,B,A`（`--round-trips 2`）：A 到位 3 次、B 到位 2 次，
最后停在 A，**不自动回零**。`--round-trips 1` 被拒绝，因为 B 只有
1 次到位，无法给出该目标的重复性。

目标由现场在**新的 T0 只读**后确定并写入授权，不由驱动从历史基线
推算；2026-10-22 执行卡的 A/B 值不能直接沿用。间距按两个到位区间
计算：每个目标的到位容差为 ±τ 时，至少一个轴必须满足
`|A-B| > 2τ`，否则两个目标可能共享同一个合格反馈位置。驱动默认
`τ=0.2°`（`--arrival-tolerance`），因此要求 `max(|Δaz|,|Δel|) > 0.4°`；
恰好 `0.4°` 仍拒绝（区间重叠）。选定 A/B 后按**实际配置的到位容差**
核对；间距不足或 A=B 时直接拒绝启动，不自动扩大现场行程。
`--min-separation` 只能加严，不能放宽 `2τ`。

## 2 驱动判据

| 项 | 判据 |
|---|---|
| 命令 | 每条 `move <A或B的az> <el>` 只发一次，不重试；固定 5 条 |
| 间距 | 至少一轴 `max(|Δaz|,|Δel|) > 2τ`；默认 τ=0.2° 即 `>0.4°`，否则不启动 |
| 到位 | 只认 `ARRIVAL_OBSERVED`，且 `feedback_only=1` |
| 序号 | `seq` 必须等于本条 `MOVE_ACCEPTED` 分配的序号 |
| 目标 | 行内 `target=[az,el]` 必须等于本条命令目标（±1e-4） |
| 轮次 | `cycle` 不得与本次会话已采用的到位轮次重复 |
| 期限 | 到位截止从 `move` 写入 stdin 起算；等待与事件处理共用截止，晚于截止收到/处理的行不释放下一条 |
| 统计 | 按目标分组；反馈偏差、均值、总体标准差、极差、最大绝对偏差 |
| 交叉核对 | 解析工具退出时的 `REPEAT` 行，与驱动统计逐目标比对（±5e-4） |
| 失败 | 任一步失败/超时：不重试、不回零；`move` 已写入但受理未知或已受理未到位时，只发一次 `stop`，再 `quit` |
| 日志 | 驱动日志写入 `OSError` 后立即停止后续定位；已发出运动进入停止收尾，本次不成功 |
| 收尾 | 完整收集到 EOF、`FINAL normal_exit=1`、日志 `EXIT_CODE 0`、子进程 `Popen.returncode=0` 才可能成功 |

`REPEAT` 交叉核对缺失或不一致时驱动判失败，避免“统计口径悄悄变了
但结果仍被采用”。`REPEAT` 本身也是设备反馈统计，不提升证据等级。

## 3 命令

```bash
python3 tools/t4_acceptance_driver.py \
  --tool build-native-on/turntable_acceptance \
  --config <现场配置目录> --permit <本次T4许可> \
  --a-az <A方位> --a-el <A俯仰> \
  --b-az <B方位> --b-el <B俯仰> \
  --round-trips 2 --arrival-tolerance <实际到位容差τ> \
  --expect-az-min <下限> --expect-az-max <上限> \
  --expect-el-min <下限> --expect-el-max <上限> \
  --log <完整日志> --notes <统计与判据>
```

`--expect-*` 只做启动前静态核对；真正的运动放行仍由工具读取许可文件
决定。许可写**恰好** `max_executions=5`，对应唯一一组 `A,B,A,B,A`
（5 条定位），不写“≥5”、不预留补跑额度；另需
`allow_absolute_position=1`、`allow_stop_at_rest=0`、
方位/俯仰范围同时包含 A 和 B、`max_displacement` 覆盖“执行前当前位置
→ A”和“A↔B”的实际位移。现有 T3 许可 `max_executions=1`，已用尽，
不得复用。

执行前仍需现场填写人员、时间窗、独立停止措施、方向与机械/线缆条件；
驱动不代填授权，也不在读数变化时自动扩大范围。

## 4 离线验证

假工具只模拟 `turntable_acceptance` 的 stdin/stdout，不连接设备、
不发 UDP。**17/17 通过**（原 12 条 + 5 条反例），完整输出见
`02_T4驱动测试输出.txt`。

| # | 用例 | 断言要点 |
|---|---|---|
| 1 | 正常 `A,B,A,B,A` | 5 次到位；A n=3、B n=2；偏差/标准差分组正确 |
| 2 | 末尾停在 A | 恰 5 条 move、1 条 quit、无 stop、无第六条运动 |
| 3 | 旧 seq 到位行 | 拒绝并继续等本次到位；5 个 cycle 互不相同 |
| 4 | 到位超时 | 只发 1 次 stop，收到 `STOP_RESULT`，再 quit |
| 5 | 命令失败 | 只发 1 次 stop 收尾 |
| 6 | 命令被拒 | 无运动、不发 stop，quit 收尾 |
| 7 | cycle 复用 | 第二次不得计为到位；超时后 stop |
| 8 | 目标不符 | 到位行被拒；超时后 stop |
| 9 | `REPEAT` 不一致 | 五步都到位也判失败（`repeat_crosscheck`） |
| 10 | 工具日志退出码非 0 | 判失败 |
| 11 | 目标超出预期包络 | 返回 2，不启动工具 |
| 12 | 单次往返 / A=B / 间距 0.03° | 均返回 2，不启动工具 |
| 13 | 日志 `EXIT_CODE 0`、真实退出 3 | `process_exit_code`，不得成功 |
| 14 | 日志写入持续 `OSError` | 0 条 move、0 次 stop、`outcome=log_error` |
| 15 | 主线程暂停，150 ms 到位超过 50 ms 期限 | `LATE_EVENT`，不得计为到位；进入等待前暂停也不顺延截止 |
| 16 | move 已写入但无 `MOVE_ACCEPTED` | `move_ack_timeout` 后仍发 1 次 stop 并记录 `STOP_RESULT` |

## 5 边界

* 只证明驱动能按固定 A/B 逐条下发、按目标分组统计反馈偏差与重复性；
* 实机结论只作为**本轮**对 A 点 3 次、B 点 2 次到位的反馈重复性观察，
  不外推到其他行程、速度或批次；
* 不证明设备 ACK、独立物理位置、绝对精度、制动性能或 1′ 指标；
* 实机未执行；执行前需新的 T0 读数、固定 A/B、按实际到位容差核对
  `|A-B|>2τ` 与书面授权；T3 已按本次功能范围关闭（`fc75240`），
  不要求重测 T3；
* 失败即结束，不重试定位、不自动回零、不扩行程或升速。
