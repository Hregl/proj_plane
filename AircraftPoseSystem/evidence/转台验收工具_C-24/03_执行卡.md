# 转台实机验收执行卡（T0–T5）

> **本卡是待确认的执行方案，不是运动授权。**
> 状态：`已实施待验证`。在用户书面确认本卡参数、并另行给出
> 实机运动授权（设备、轴、角度范围、时间、操作者、急停方式）之前，
> **不得执行 T1–T5 的任何运动指令**。
>
> 工具：`turntable_acceptance` `1.0.3-C24`
> 构建：`build-native-off`（现场建议使用与离线验证相同的构建）
> 配置：`use_speed_control=false`（设备默认速度）

## 1. 现场前置（全部满足才可开始）

| # | 前置 | 判据 |
|---|---|---|
| P1 | T0 只读复测完成 | 控制帧 0（工具计数 + 抓包双证）；样本 `valid`、`fresh`；正常退出 |
| P2 | 实际设备速度已确认 **（当前未取得，阻塞 T3）** | 从设备面板/说明书/维护记录取得**默认速度数值**并记录**来源**；`use_speed_control=false` 只表示“定位指令不带速度字段”，**不等于速度已确认**；`fine_speed`/`coarse_speed` 不是受控速度。未取得前不得执行 T3（见 §3 T3） |
| P3 | 设备身份记录 | 型号/序列号（可见则记录）、`pelco_address`、端口；**host 在进库记录中脱敏** |
| P4 | 抓包就绪 | 现场主机对 UDP 6666 抓包；原始 pcap 存 `验收证据/`，逐件 SHA-256 |
| P5 | 停止手段就位 | 见 §5；工具停止路径可用，且**独立停止措施**（设备停止/急停按钮或断动力）在操作者可立即执行范围内 |
| P6 | 现场人员 | 设备旁 1 人专职执行**独立停止措施**；操作者 1 人只发命令 |
| P7 | 许可文件已生成（T1 前） | 以 T0 的 R 为基准；本卡 §2 数值；有效期覆盖 T1–T4 |
| P8 | 书面授权 | 明确设备、轴、角度范围、次数、时间窗、操作者、停止方式 |

## 2. 许可参数（以 T0 的同一轮双轴样本 R=(az0, el0) 为基准）

T0 结束后**只取一轮** `valid && fresh` 的样本作为 R，写入许可：

| 键 | 值 | 说明 |
|---|---|---|
| `scope_id` | `TURNTABLE_ACCEPT_<日期>_<序号>` | 本次一次性范围 |
| `device_host` | 现场设备地址 | 只存 `验收证据/`；进库脱敏 |
| `device_port` | `6666`（按现场配置） | 与 `turntable.yaml` 一致 |
| `pelco_address` | `1`（按现场配置） | 帧地址，不是 IP |
| `allow_absolute_position` | `1` | 只允许绝对定位 |
| `allow_stop_at_rest` | `1` | 仅 T1 需要：静止时实际发一帧停止。必需键，缺失即解析失败 |
| `azimuth_min_deg` | `az0 - 2.0` | 若 `az0 < 2.0`，改用 `[az0, az0 + 2.0]`，禁止跨 0/360 数值回绕 |
| `azimuth_max_deg` | `az0 + 2.0` | 同上，单侧范围 |
| `elevation_min_deg` | `el0 - 1.0` | 不跨俯仰限位 |
| `elevation_max_deg` | `el0 + 1.0` | 同上 |
| `max_displacement_deg` | `2.0` | 单次目标相对当前实测角的最大位移 |
| `max_executions` | `10` | T2 四次 + T3 一次 + T4 五次；**无自动重试配额** |
| `valid_from_epoch_ms` | 生成时刻 | 现场生成 |
| `valid_until_epoch_ms` | 生成时刻 + 90 min | 覆盖 T1–T4；过期只拒新运动，停止不受影响 |

> 方位角按数值区间核对，不是环形区间。R 距 0/360 小于 2° 时使用
> 单侧范围，并在记录中写明原因。
>
> 本卡**不设置**额外运动次数。任一命令结果不符合预期时，停止并
> 结束本卡，不靠“再来一次”凑结果；如需重测，重新确认许可。

### 2.1 以 2026-10-22 T0 实测基准填入的具体值

T0 读到的同一轮双轴样本：**R = (az0, el0) = (-0.1200°, 0.0500°)**。
若 T0 重跑，以下值必须按新的 R 重算，不得沿用。

| 项 | 具体值 |
|---|---|
| 许可方位范围 | `[-2.1200°, +1.8800°]` |
| 许可俯仰范围 | `[-0.9500°, +1.0500°]` |
| T2a 方位正向 | `move az 0.3800`（el 目标取同轮 reference） |
| T2b 方位反向 | `move az -0.1200` |
| T2c 俯仰正向 | `move el 0.3500`（az 目标取同轮 reference） |
| T2d 俯仰反向 | `move el 0.0500` |
| T3 运动中停止 | `move az 1.3800`（取正向一侧，距许可上界 0.5°） |
| T4 A/B | A=`(0.3800, 0.0500)`，B=`(-0.1200, 0.0500)`，A 点到 3 次 |
| T5b 目标 | 拔线前最后一个新鲜方位角 C（目标=当前位置） |

## 3. 执行顺序与判据

### T0 只读 + 正常退出（不安装许可）

```bash
./turntable_acceptance --config <现场配置目录> --observe-ms 60000
```

| 记录 | 通过判据 |
|---|---|
| `PERMIT none`、`SEND_POLICY read_only` | 只读会话 |
| `INIT_OK`、周期 `status` | 双轴样本 `valid=1`、`fresh=1`，`cycle` 递增 |
| `FINAL control_frames=0 query_frames>0` | 工具计数控制帧 0 |
| 抓包 `udp port 6666` | 除查询帧外**控制帧 0**（0x4B/0x4D/0x00 均不出现） |
| `EXIT_CODE 0`、`normal_exit=1` | 正常退出 |

T0 结束取一轮样本作为 R，生成许可。

**T0 已执行（2026-10-22，实机只读）**：`INIT_OK`；60 s 内 2003 帧 TX
全为查询（0x51×1001、0x53×1001、0xE0×1），控制帧 0；61 条状态全部
`valid=1 fresh=1`、`IDLE`；`az=-0.1200°`、`el=0.0500°`；
`wm=EchoOnly`；正常退出、退出码 0。独立抓包因现场无 `tcpdump`/
`dumpcap`/`tshark` 且无 `CAP_NET_RAW` 未执行，控制帧为 0 来自工具传输
seam 的逐帧日志，**独立抓包仍是缺口**。详见
`05_T0_实机只读_记录.md`。本次读到的 R 可作为 T1 许可的初始基准，
但 T1–T5 仍需确认本卡并另行书面授权。

### T1 静止停止帧（许可已安装，无运动）

```bash
./turntable_acceptance --config <现场配置目录> --permit <许可文件>
# 初始化后输入：
stop_at_rest
quit
```

本步用 `stop_at_rest`（`sendAcceptanceStopFrameAtRest()`）在**静止**状态
实际发送一帧 `0x00`；普通 `stop` 在静止时是无帧 no-op，**不能**记作 T1。

| 记录 | 通过判据 |
|---|---|
| `PERMIT ... allow_stop_at_rest=1` | 许可显式授权静止停止帧 |
| `STOP_AT_REST_REQUEST at_motion=IDLE fresh=1` | 发起时静止且样本新鲜 |
| `STOP_AT_REST_RESULT ok=1 control_frames_added=1` | **恰好新增 1 个控制帧** |
| `stop_delivered=1`（随后 `STOP_OBSERVED_STATIONARY`） | 停止帧已交付传输层；观测窗口内反馈角不变 |
| 再次 `stop_at_rest` → `ok=0 control_frames_added=0` | 本会话不重复补帧 |
| `EXIT_STOP` 不增加控制帧；`FINAL control_frames=1` | 退出路径不补发 |
| `EXIT_CODE 0` | 正常退出 |

> `control_frames_added=1` 只证明工具经生产发送路径发出了 1 帧，不证明设备
> 收到、执行或物理停止。独立抓包若仍不可用，按 T0 的缺口如实记录。
> 本帧**不计入**运动执行次数（`max_executions` 只统计绝对定位）。

### T2 单轴小步正/反向（每次只改一个轴的目标）

每次 `move az` / `move el` 的未变轴目标取**同一轮** `MOVE_REQUEST`
里的 `reference_az`/`reference_el`；不得用另一次采样的值拼接。

| 步 | 命令 | 目标 | 通过判据（除“反馈到目标±0.2°”外） |
|---|---|---|---|
| T2a | `move az <az0 + 0.5>` | az 正向 | 方位反馈增大；俯仰目标 = 同轮 `reference_el`；俯仰反馈保持 |
| T2b | `move az <az0>` | az 反向 | 方位反馈减小；俯仰目标 = 同轮 `reference_el` |
| T2c | `move el <el0 + 0.3>` | el 正向 | 俯仰反馈增大；方位目标 = 同轮 `reference_az` |
| T2d | `move el <el0>` | el 反向 | 俯仰反馈减小；方位目标 = 同轮 `reference_az` |

每步记录：`MOVE_REQUEST`（含 `reference_cycle`、`reference_*`、
`reference_fresh=1`、`speed_control=0`）、`MOVE_ACCEPTED`、
`CMD_RESULT delivered_is_arrival=0`、`ARRIVAL_OBSERVED`
（`elapsed_ms` 用于估算观测速度，不是受控速度）。

> “单轴”指**只改变一个轴的目标**，不是“只发一帧”。绝对定位帧
> 仍可能包含两个轴的数据；判据看目标与反馈，不看帧数。

### T3 运动中停止（行程不足以在运动中停下时，记录未完成）

| 项 | 值 |
|---|---|
| 前置 | **P2 实际默认速度已记录（当前未取得 ⇒ T3 不执行）**；不得用 T2 的 `ARRIVAL_OBSERVED elapsed_ms` 反推速度作为确认 |
| 命令 | `move az <az0 + 1.5>`（或反向 `<az0 - 1.5>`，取离限位更远的一侧） |
| 停止方式 | 操作者在本终端紧接着输入 `stop`（走生产停止路径，与 `quit`/`Ctrl-C` 同一程序与通信链） |
| 通过判据 | `STOP_REQUEST at_motion=MOVING`；`STOP_RESULT stop_delivered=1`；随后 `STOP_OBSERVED_STATIONARY`；`stop_txn == motion_txn_before` |
| 未完成判据 | `stop` 到达时 `at_motion` 已为 `STABLE`，或 `stop_delivered=0` 且 `send_path=no_frame(no_motion_in_flight)` → 记录 **T3 未完成（行程过短）** |
| 禁止 | **不得**为了完成 T3 放大行程、提高速度或改设备速度 |

T3 的 `STOP_OBSERVED_STATIONARY` 只表示“观测窗口内反馈角不变”，
不是设备 ACK，也不是独立实测物理静止。

### T4 重复定位（只统计设备反馈重复性）

以 A=`(az0 + 0.5, el0)`、B=`(az0, el0)` 往返，**人工逐条下发**：

```text
move az <az0 + 0.5>   # A，到位后记录
move az <az0>         # B，到位后记录
move az <az0 + 0.5>   # A
move az <az0>         # B
move az <az0 + 0.5>   # A（第 5 条，最后停在 A）
quit
```

**T4 结束位置是 A=`(az0 + 0.5, el0)`，不是基准点 B。** 不追加回零，
也不把 B 当作结束点。

| 记录 | 通过判据 |
|---|---|
| 三次 `ARRIVAL_OBSERVED` 到 A | 每次 `cycle` 不同、`feedback_only=1` |
| `REPEAT n=3 target_az=<A> ... az_std=...` | 工具按目标分组输出；不得把 A/B 混合统计 |
| 结论边界 | 只给**设备反馈重复性**；`absolute_accuracy=NOT_MEASURED`、`arcmin_acceptance=NOT_MEASURED` |

### T5 故障场景（不产生运动）

**T5a 只读失联（不安装许可）**

1. 只读会话初始化成功后，拔掉测试链路（或在交换机上禁用该端口）≥5 s；
2. 观察 `MOTION_ERROR`/通信故障诊断，`first_fault` 记录首个错误；
3. 全程 `control_frames` 保持 0；
4. 恢复链路，`quit` 正常退出；如故障已锁存，记录 `latched=1`。

**T5b 锁存故障下许可不能放行**

1. 新开许可会话（许可 `max_executions=1`，范围仍为 §2），初始化成功；
2. 不运动，拔链路 ≥5 s，直到故障锁存；
3. 记拔线前最后一个新鲜方位角为 C，输入 `move az <C>`（目标=当前位置，
   即使门禁失效也**不产生位移**）；
4. 通过判据：`MOVE_NOT_ACCEPTED` 或 `CMD_RESULT outcome=Failed`；
   `control_frames` 不增加；`WorkModeTrust` 保持实际值，不因许可改写；
5. 恢复链路，`stop`、`quit`。

**T5c 样本过期/无效**：如现场没有不破坏设备的注入手段，
记录 **T5c 未执行（无安全注入手段）**；该路径由离线用例
`StaleSampleBlocksPermitMotion` 覆盖，不冒充实机证据。

## 4. 次数与时间

| 项 | 值 |
|---|---|
| **上层定位命令总数** | **10 条**：T2 4 条 + T3 1 条 + T4 5 条 |
| 与帧数的关系 | **10 条上层命令 ≠ 10 个控制帧**。每条绝对定位命令在实现中按两轴拆分发送；底层发送失败时可能按既有重试策略重传；实际帧数从 `FINAL control_frames` 与逐帧 TX 日志读取并**单独报告**。不得用命令数推算帧数，也不得用帧数反推命令数。T1 的 1 帧也计入 `FINAL control_frames`，报告时单列，不算运动帧 |
| 计数不含 | 重做 T3、额外回零、T5b 的“目标=当前位置”命令（若其零帧被拒，不计入 10 条；若发生发送，立即中止并按异常记录） |
| 许可上限 | `max_executions=10`，只统计**被受理的绝对定位命令**；T1 静止停止帧不计数 |
| 速度条件 | **实际默认速度：未取得（阻塞 T3）**。`use_speed_control=false` 只表示定位指令不带速度字段；本卡不指定、不改变速度，`fine_speed`/`coarse_speed` 不是受控速度。P2 记录**数值与来源**之前不得执行 T3；T2 的 `ARRIVAL_OBSERVED elapsed_ms` 只作观测值，不能当作速度确认 |
| 自动循环/自动重试/自动回零 | **无**；每条命令由操作者单独输入；**不重做 T3、不追加回零** |
| 预计现场时间 | T0 约 2 min；T1–T2、T4 约 10–15 min；T3 待速度确认；T5 约 5 min |

## 5. 现场停止方式

**正常中止使用工具停止路径。出现异常运动、程序无响应或通信失效时，现场
操作者直接按设备规程使用独立停止措施，不要求依次等待软件操作。**

**工具停止路径**：`stop`、`quit`、`Ctrl-C`（SIGINT/SIGTERM）。

* 三者**共享同一程序与通信链**，不是三套独立保障：
  * `stop`：走生产停止屏障，记录 `STOP_REQUEST/RESULT`；
  * `quit`：走退出路径，先停止、等待观测窗口，再关闭；
  * `Ctrl-C`：工具 `1.0.3-C24` 捕获 SIGINT/SIGTERM 后进入同一停止/退出
    路径（`SIGNAL_INTERRUPT`），不是直接杀进程。
* 程序无响应、进程崩溃或通信失效时，上述三条都可能**同时失效**；
  此时不得继续等待软件操作。

**独立停止措施**（由现场操作者按设备规程直接执行，与工具程序/通信链无关）：

* 设备控制器上的停止/急停按钮（若配备）；
* 断开设备动力——最后手段，仅在确认人员与设备安全后执行，并记录时间与原因。

停止后的判读顺序：`stopFrameDelivered`（交给传输层）→
`stopObservedStationary`（观测窗口内反馈角不变）→ **无设备 ACK 证据**。
任一阶段为 `motionUncertain=1`，立即使用独立停止措施并终止本卡。

## 6. 立即中止条件（任一出现）

* T0/T5a 只读会话出现任何控制帧；
* 目标方向与预期相反，或未变轴反馈超出 `arrival_tolerance_deg`；
* 运动中出现人员进入、线缆受拉、异常噪声、限位接近；
* `STOP_RESULT stop_delivered=0`（且并非静止 no-op），或
  `STOP_NOT_OBSERVED`、`motionUncertain=1`；
* 许可本应拒绝却出现控制帧；
* 样本持续 `stale`、`first_fault` 为 2001/2005/2006/2008；
* 实际速度明显高于前置确认值，导致无法安全停止。

中止动作：正常中止使用工具停止路径；程序无响应、通信失效或异常运动时，
现场操作者**直接**使用独立停止措施（见 §5），不依次等待软件操作。
保留现场日志与抓包；**不重跑整段序列**。

## 7. 每条记录必须包含

| 类别 | 字段 |
|---|---|
| 来源 | 源码 SHA、工具版本、实际配置（脱敏）、设备身份、验收范围 |
| 原始帧 | TX/RX 字节、单调时间戳；pcap 文件与 SHA-256 |
| 样本 | 双轴角度、`cycleId`、`valid`、`fresh`、采样时刻 |
| 命令 | 序号、目标、`reference_cycle`、受理结果、`CMD_RESULT`、事务 ID |
| 停止 | `stopFrameDelivered`、`stopObservedStationary`、`motionUncertain`、首个故障、停止事务与运动事务归属 |
| 退出 | 现场观察、`normal_exit`、退出码、关闭后无发送 |

## 8. 待用户确认的参数

1. 设备、端口、`pelco_address` 与现场配置目录；
2. T2 步长 `0.5°/0.3°`、T3 步长 `1.5°`、T4 目标 A/B；
3. 许可位移上限 `2.0°`、次数 `10`、有效期 `90 min`；
4. 现场停止方式（§5）：工具停止路径是否可用、独立停止措施（设备停止/
   急停、断动力）的具体操作与位置；
5. 实际默认速度的数值与来源（P2；未取得前 T3 不执行）；
6. 书面运动授权（设备/轴/范围/时间/操作者/停止方式）。

本卡参数确认后，才生成许可文件并执行 T1；T0 可先行。
