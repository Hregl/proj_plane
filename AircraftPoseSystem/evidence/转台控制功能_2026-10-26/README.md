# 主程序受控转台操作入口：虚拟窗口连续操作（2026-10-26）

本目录留存**主程序真实窗口**（Qt GUI，非离屏）下，用虚拟转台后端完成的
一次连续操作演示：待机 → 定位 → 运动中断言互斥 → 到位 → 再次定位 → 停止
→ 停止后再次到位 → 正常关闭。

## 1 本目录证明什么、不证明什么

**证明（界面层可复核的事实）**

1. 当前命令的**交付与到位归属**：运动中只显示“指令已交付”，到位只在本条
   命令被控制器报告 `Delivered` 且反馈 `STABLE` 且在容差内之后出现
   （`02` → `02b`）；停止后重新定位走同一条判据（`04`）。该判据的读端顺序
   （先读交付事实、后取状态快照，motion 与角度取自同一份快照）由离线用例与
   变异检查覆盖（`10`/`11`），本目录的虚拟后端截图只是界面流程演示。
2. **未完成时的操作互斥**：上一条定位未结束时，“定位”按钮不可用，门禁行
   显示“上一条定位尚未结束”，只有“停止”可用（`02`）。
3. **停止与状态收口**：停止后命令阶段“被停止取消”、停止阶段如实显示
   “未发送停止帧 / 虚拟转台就地停止（无协议帧；不是设备 ACK）”（`03`），
   停止预算/未停收口的**代码路径**由离线的 `08`/`09` 覆盖。
4. 应用在真实窗口下**连续操作不崩、不误报**，关闭后进程退出码 0（`07`）。

**不证明（不得据此升级结论）**

* 虚拟后端（`VirtualTurntable`，`protocol: sdk`）**不产生任何协议帧**：
  没有 Pelco-D 发送、没有回显、没有设备 ACK。截图里的“已连接（虚拟转台）”
  与界面自带的“虚拟后端：不是实机链路证据”是同一件事。
* 不证明真实链路时延、真实转台的到位/制动、物理静止或停止时长。
* 不证明验收许可链路：界面“许可”行为“虚拟转台：不适用验收许可”。
* 不涉及漂移根因、绝对精度与 1′ 指标（按约定留在后续测量质量阶段）；
  T3/T4 驱动保持关闭，本批未运行。
* 本目录**不替代**任何实机证据；实机运动仍需当次有效书面授权。

## 2 运行环境与采集方法

| 项 | 值 |
|---|---|
| 构建 | `build-dev`（本工作树，含本批修复；`10-26` 由同一份源码重建，产物大小一致） |
| 配置 | `AircraftPoseSystem/simulation/config`（三路虚拟相机 + 虚拟转台），模型目录 `simulation/models` |
| 显示 | `DISPLAY=:0`，1920×1080；窗口客户区 1600×1064（窗口高 1064 > 屏幕可用高度，故底部会被屏幕裁掉**显示**，但截图按窗口 ID 抓取完整客户区） |
| 启动 | `DISPLAY=:0 build-dev/AircraftPoseSystem simulation/config`（工作目录含 config/models 软链接） |
| 截图 | `ffmpeg -f x11grab -window_id <id> -video_size 1600x1064 -i :0.0 -frames:v 1`；按窗口 ID 抓取，**完整客户区**（含按钮、阶段、反馈），不含标题栏。ffmpeg 会打印无害的 X 访问错误，抓取时丢弃 stderr |
| 操作 | `xdotool`：点击输入框 → `Ctrl+A` → 输入 → `Return` 提交；按钮用 `Tab` 聚焦 + `Space` 激活 |

> 操作方式说明：本次采集中，对本窗口按钮发送“鼠标按下+释放”只观察到按压态、
> 未观察到 `clicked`（`Return` 亦未激活已聚焦的 `QPushButton`），故改用
> `Tab`+`Space` 的键盘激活路径。**这只是采集侧的已观测现象，原因尚未证实**：
> 现有材料不足以断定它由输入方式（窗口焦点、点击注入方式、桌面主题等）引起，
> 也不足以断定它不是程序缺陷。本目录的界面流程验收**仅覆盖 `Tab`+`Space`
> 路径**，不构成鼠标激活可用或不可用的结论。

| 目标 40.0/15.0 启动后约 0.8 s 按停止 | `03_停止后.png` | 状态 `IDLE`；命令阶段“被停止取消 / 定位命令被停止请求取消”；停止阶段“未发送停止帧 / 虚拟转台就地停止（无协议帧；不是设备 ACK）”；最近操作“停止请求已发出（不表示设备已停止）”；反馈保持 `5.0000 / 2.0000`（虚拟转台就地停止，不上报中途角度） |
| 目标 12.0/5.0（停止后再次定位） | `04_停止后再次到位.png` | 反馈 `12.0000 / 5.0000`；`STABLE`；命令阶段“反馈已到位”；停止阶段“未请求停止” |
| 点击标题栏 × | `07_正常关闭退出码_exit-code.txt` | 进程退出码 **0**，窗口消失，无残留进程 |
